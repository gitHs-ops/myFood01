# 오늘의 반찬 — 메뉴 관리 가이드 (운영자 사용 매뉴얼 ver 1.0)

작성: 2026년 4월 | 원본: `onban_manual.html` (menu-manager.html 사용 설명, 초기 버전)

## 이 매뉴얼에 대해
이 서비스는 두 개의 페이지로 구성되어 있습니다.

| 페이지 | 누가 사용 | 하는 일 |
|---|---|---|
| 🔒 메뉴 관리 페이지 (menu-manager.html) | 점주님 (혼자만) | 메뉴 등록, 사진 추가, 재고 관리, 카카오 발송 문자 생성 |
| 🛒 고객 주문 페이지 (onban.html) | 고객 | 메뉴 확인, 장바구니, 주문, 결제 안내 |

이 매뉴얼은 점주님이 사용하시는 "메뉴 관리 페이지"를 설명합니다.

## 메뉴 관리 페이지 열기
주소: `https://giths-ops.github.io/myOnban/menu-manager.html`
북마크(즐겨찾기)에 저장해 두면 매일 편하게 열 수 있습니다.

화면 구성: 날짜 선택 바 / 메뉴 관리·카카오 발송·가져오기·메뉴 창고 탭 / 메뉴 수·총 재고·어린이 가능 현황 자동 표시.

## 1. 날짜 선택하기
- 날짜 버튼을 클릭하면 달력이 열립니다.
- 원하는 날짜를 탭하면 그 날짜의 메뉴 화면으로 전환됩니다. 🟡 주황 점 = 이미 메뉴가 저장된 날.
- ◀▶ 버튼으로 하루씩 이동, "오늘" 버튼으로 오늘 날짜로 복귀.
- 내일 메뉴를 오늘 미리 입력해 둘 수 있습니다. 고객 페이지는 오늘 날짜 메뉴를 먼저 보여주고, 없으면 가장 최근 날짜 메뉴를 자동으로 표시합니다.

## 2. 일일 메뉴 등록하기
1. 메뉴명 입력 — 과거에 쓴 이름이 자동 추천됨. 오늘 목록에 이미 있는 메뉴면 중복 경고 표시.
2. 금액 입력 (천원 단위, 예: 10,000원 → 10)
3. 재고 수량 입력 — 0이면 고객 화면에 "품절" 표시
4. 카테고리 선택 (메인/반찬/김치/밀키트/기타)
5. 어린이 가능 체크 (선택) — 고객 화면에 👧 표시
6. "추가" 버튼 클릭 → 메뉴 목록에 즉시 추가, 입력창 자동 비워짐

💡 메뉴명 입력 후 Enter 키를 눌러도 추가됩니다.

## 3. 사진 등록하기
1. 메뉴 목록에서 각 메뉴 왼쪽 📷 버튼 클릭 → 사진 등록 창 열림 (이미 등록된 메뉴는 썸네일 표시)
2. "📁 사진 선택" 버튼으로 사진을 고름
3. 자동 업로드 — "업로드 중..." → "업로드 완료!" 후 창 닫힘

| 버튼 | 기능 |
|---|---|
| 📁 사진 선택 | 새 사진 등록 또는 기존 사진 교체 |
| 삭제 | 등록된 사진 삭제 |
| 취소 | 변경 없이 창 닫기 |

💡 사진은 인터넷에 안전하게 저장되어 다른 기기에서도 그대로 보입니다.
⚠ 인터넷이 연결된 상태에서만 사진 업로드가 됩니다.

## 4. 재고 수량 변경하기
- + 버튼: 수량 1개씩 증가
- − 버튼: 수량 1개씩 감소. 0이 되면 고객 화면에 "품절" 표시.

💡 재고가 0이어도 고객 화면에서 메뉴가 보입니다. 품절 표시와 함께 "전화 문의 가능" 안내가 자동으로 표시됩니다.

## 5. 금액 수정하기
1. 메뉴 목록에서 금액 숫자를 클릭하면 입력창으로 전환
2. 새 금액 입력 (천원 단위)
3. Enter 또는 다른 곳 클릭 시 저장. 취소하려면 Esc.

## 6. 메뉴 삭제하기
1. 메뉴 오른쪽 ✕ 버튼 클릭
2. 확인 창에서 "확인" 클릭 시 삭제

⚠ 삭제한 메뉴는 복구할 수 없습니다.

## 7. 카카오 발송 문자 복사하기
1. "카카오 발송" 탭 클릭
2. 노란색 박스에 오늘 날짜·카테고리별 메뉴 목록·주문 링크가 자동 완성되어 표시
3. "📋 텍스트 복사하기" 버튼 클릭 → "복사 완료!" 표시

💡 맨 아래 주문 링크가 자동으로 포함되어 따로 입력할 필요가 없습니다.

## 8. 카카오 채널에 붙여넣기
1. 카카오 비즈니스 채널 관리자 페이지 열기
2. 메시지 입력창 클릭 후 Ctrl+V(PC) 또는 길게 눌러 붙여넣기(스마트폰)
3. 내용 확인 후 발송

## 9. 카카오 텍스트 가져오기
이미 카카오에 보낸 메뉴 텍스트를 붙여넣으면 자동으로 메뉴 목록으로 변환됩니다.
1. "가져오기" 탭 클릭
2. 카카오톡 메뉴 메시지를 복사해서 붙여넣기. 형식: `한우육전 10` (메뉴명 + 금액(천원))
3. "🔍 메뉴 자동 인식하기" 클릭 → 텍스트 분석 후 메뉴 목록으로 변환, 카테고리도 자동 추정
4. 인식된 목록 확인, 카테고리 오류 시 수정
5. "✅ 메뉴 관리로 가져오기" 클릭 → 메뉴 목록에 추가. 같은 이름 메뉴는 중복 없이 자동 처리

💡 매일 새로 입력하기 귀찮으면 이 기능을 사용. 기존에 카카오로 보내던 텍스트를 그대로 붙여넣기만 하면 됩니다.

## 10. 메뉴 창고 저장하기
1. "카카오 발송" 탭으로 이동
2. "메뉴 창고에 저장" 버튼 클릭 → 오늘 날짜로 메뉴 저장, "저장되었습니다!" 표시

💡 메뉴를 추가·수정할 때마다 자동으로 임시 저장됩니다. 메뉴 창고 저장은 나중에 불러오기 위한 별도 보관입니다.

## 11. 메뉴 창고 보기
1. "메뉴 창고" 탭 클릭 → 저장된 날짜 목록 표시
2. 불러올 날짜 클릭 → 그 날의 메뉴가 바로 표시 ("지금 작업중" = 현재 선택된 날짜)
3. 메뉴 관리 탭으로 자동 이동 → 수정 후 오늘 날짜로 다시 저장

💡 매주 비슷한 메뉴를 판매한다면 지난주 메뉴를 불러온 뒤 일부만 수정하면 시간이 절약됩니다.
