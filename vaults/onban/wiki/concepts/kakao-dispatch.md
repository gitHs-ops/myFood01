# 카카오 발송

## Overview
[[onban-service]]는 별도 주문 시스템 공지 없이 카카오톡 채널 텍스트 공지로 고객을 웹페이지 주문으로 유도한다. [[menu-manager-page]]는 이 텍스트를 **양방향**으로 다룬다: (1) 오늘 등록된 메뉴 → 카카오 발송용 문구 자동 생성, (2) 카카오톡에 이미 붙여넣은/보낸 텍스트 → 파싱해서 일일 메뉴로 재등록.

## 정방향: 메뉴 → 발송 문구
1. "오늘메뉴에서 가져오기"로 현재 일일 메뉴를 카카오 안내 형식으로 자동 생성 (카테고리별 목록 + 주문 링크 자동 포함)
2. 텍스트 칸은 항상 편집 가능 — 직접 수정해도 자동 폴링 갱신이 덮어쓰지 않음
3. "텍스트 복사하기"로 클립보드 복사 → 카카오 채널에 붙여넣기(Ctrl+V 또는 길게 눌러 붙여넣기)

## 역방향: 발송 문구 → 메뉴 (카카오 톡 내용으로 일일 메뉴 생성)
1. 카카오톡 텍스트를 발송 칸에 붙여넣고 "[카카오 톡 내용으로 일일 메뉴 생성]" 클릭
2. 파싱 결과 미리보기 표: `메뉴ID | 메뉴명 | 금액 | 재고 | 구분` + [취소]/[등록] 확인창
3. **구분 값**: `기존`(창고에 있음) · `★신메뉴`(창고에 없음) · `중복됨`(같은 이름 반복)
4. **적색 라인(확인 필요)**: 중복됨 · ★신메뉴 · 금액 10만원 이상(⚠금액확인) · 문자 깨짐(⚠문자깨짐) · 금액 없음/0/음수(⚠금액없음)
5. [취소]하면 미리보기만 남아 표에서 수정 후 재시도 가능. [등록]하면 표 내용대로 확정 — 등록 기준은 메뉴명, 중복 자동 제외, 기존 메뉴는 초기화 후 재구성

## 인식 규칙
- **금액 형식**: `한우육전 10`(천원 단위 숫자) · `6천원` · `6,000원` · `6.5천원` — 모두 인식, 천원 단위로 저장(6.5 → 6,500원)
- **재고 표기**: 문구 내 `(재고 N개)` · `(품절)` · `(준비중)` → 재고 열에 N / 0 / 조리준비중으로 반영. 표기 없으면 설정의 기본 재고값 적용

## 주의
⚠ [취소]로 미리보기만 남긴 채 다른 탭 이동·새로고침·창닫기를 하면 "아직 등록하지 않았다" 경고가 표시된다 — 등록 누락 방지용 가드.
