# 예약주문

## Overview
오늘 판매 중인 메뉴 외에, 고객이 향후 배송받고 싶은 날짜를 지정해 마스터(창고) 메뉴 전체 중에서 미리 주문하는 기능. 핵심 설계: **예약주문 전용 상태 체계가 없다** — 일반 주문과 완전히 동일한 4단계(대기중 → 주문접수 → 배송완료 / 취소된주문)를 따르며, "예약 날짜가 지정되어 있는가"만으로 일반 주문과 구분된다.

## 고객 측 흐름 ([[onban-customer-manual]] 11장)
1. 마스터 메뉴에서 카테고리별로 1개 이상 선택 (클릭 = 체크, 재클릭 = 해제)
2. 하단 플로팅 바("선택 개수 + 📅 예약 주문 신청하기") → 팝업에서 이름/전화번호/배송주소/배송방법/예약날짜/요청사항 입력
3. **예약 날짜 범위**: 오늘로부터 1일 후 ~ 7일 이내 (단, 운영자가 등록한 "예약 이벤트"는 이벤트 기한일부터 1주일 이내로 별도 규칙 적용)
4. 신청 후 날짜 변경 불가 — 잘못 선택 시 취소 후 재신청 필요
5. 배송비 규칙은 일반 주문과 동일: 합계 2만원 미만 → 매장 픽업만 가능, 2만원 이상 + 배송 선택 → 배송비 1천원 추가

## 관리자 측 처리 ([[onban-admin-manual]] 5.5절, 6.3절)
- 주문 관리 탭의 "예약주문" 필터로 모아보기 — 상태 라벨 앞에 빨간 "예약주문 / " 접두어 (예: "예약주문 / 주문접수")
- "✅ 예약 주문 접수" 시 주문 날짜가 고객이 지정한 예약 날짜로 자동 변경
- "✅ 배송완료"는 **작업일자가 예약 날짜와 같을 때만** 활성화 — 날짜가 다르면 버튼 비활성
- **재고 차감/부족 검사가 적용되지 않는다** — 일반 주문과의 핵심 차이
- 메뉴 창고 탭의 "예약된 메뉴" 하위 탭에서 접수 완료된 예약주문만 별도 조회 가능

## 예약 이벤트 (특수 케이스)
운영자가 특정 메뉴를 기간 한정으로 홍보할 때 사용. 고객 화면(메뉴 목록 + 예약주문 페이지 상단)에 배지·설명·기한 카드로 노출되며, 클릭 시 바로 신청 팝업이 열린다. 같은 전화번호+같은 날짜 중복 신청은 서버에서 자동 거부.
