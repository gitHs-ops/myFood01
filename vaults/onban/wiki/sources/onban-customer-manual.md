# 온반 고객 페이지 사용 매뉴얼

## Overview
onban.html(고객 주문 페이지)의 전체 화면 흐름을 다루는 2026-08-10자 매뉴얼. 메뉴 목록 → 상세 팝업/페이지 → 장바구니 → 주문자 정보 → 주문 확정 → 결제 안내로 이어지는 기본 주문 흐름과, 예약주문·AI추천메뉴(이미지 갤러리)·나의 기록·FAQ까지 14개 장으로 구성된다.

## Key Takeaways
- **로그인 없이 기기 식별로 개인화**: 이름·전화번호·주소1 자동 채우기, "나의 기록"(주문/예약 요약, AI추천 선택 이력, 자주 살펴본 메뉴 TOP 10)이 모두 별도 로그인 없이 기기 단위로 동작한다.
- **장바구니는 임시 저장**: 새로고침하면 초기화되므로 담은 즉시 주문 진행을 권장 (FAQ 14장).
- **배달 기준선은 2만원**: 장바구니 합계 2만원 이상 시 배달 가능(배달료 1천원 추가), 미만이면 매장 픽업만 가능 — 예약주문에도 동일하게 적용됨 → [[reservation-order]]
- **예약주문은 오늘로부터 1~7일 이내만 가능**: 단, 운영자가 등록한 "예약 이벤트"에 한해서는 이벤트 기한일부터 1주일 이내로 범위가 달라짐 (11.6절). 예약 날짜는 신청 후 변경 불가 — 취소 후 재신청해야 함.
- **AI추천메뉴는 3가지 범위**: 오늘의 메뉴 / 전체 메뉴 / 개인취향(과거 조회·선택 이력 기반) 중 선택해 3~6개를 추천받고, 여러 개를 한 번에 예약주문으로 넘길 수 있다 (과거엔 1개만 가능했음) → [[ai-menu-recommendation]]
- **알림톡·SMS는 관리자 매뉴얼과 대응**: 배송완료 시점에만 고객에게 알림톡이 가는 이유([[onban-admin-manual]] 7.4절 참고)가 이 문서의 "관리자 답변" 개념(채팅 버블 표시)과 연결된다.

## Detailed Notes

### 화면 전환 구조
단일 HTML 앱(SPA 방식)으로 페이지 새로고침 없이 상단 버튼으로 화면 전환. 상단 네비: 메뉴 목록 / AI 추천메뉴 / 설명서 / 장바구니(뱃지) / 주문내역 / 예약주문 / 나의 기록.

### 메뉴 목록
카테고리: 전체/메인/한우/한돈/반찬/김치/밀키트/기타. 재고 3개 이하면 "⚠ N개 남음" 경고 태그, 0이면 "품절"(선택 불가). 어린이 식단 메뉴는 노란 태그 + 카드 좌측 노란 테두리.

### 장바구니 → 주문 흐름
장바구니(수량 조절, 선택 삭제) → 주문자 정보 입력(자동 채우기 + 저장 주소 최대 3개, 매장 픽업 시 주소 불필요) → 주문 확정하기(총액 강조 표시) → 결제 안내(계좌이체, 계좌번호 복사 버튼).

### 주문 내역
상태: 접수중 / 확인됨 / 배달완료 / 취소됨. 접수중 상태에서만 수량 변경·항목 삭제·주문 취소 가능. 확인됨/배달완료 이후 취소 불가(관리자 직접 연락 필요). 추가 요청은 언제든 입력·수정 가능하며 관리자 답변은 초록 채팅 버블로 표시.

### 예약주문 ([[reservation-order]] 참고)
마스터(창고) 메뉴 전체에서 선택 → 하단 플로팅 바로 신청 → 팝업에서 이름/전화번호/배송정보/예약날짜/요청사항 입력. 처리 흐름은 일반 주문과 동일(대기중→주문접수→배송완료), 예약 날짜 지정 여부만 다르다.

### AI추천메뉴 (이미지 갤러리, [[onban-image-gallery]] · [[ai-menu-recommendation]])
사진 갤러리 형태로 메뉴를 훑어보고, 조건(식사 목적/형태/음식 종류/국물/맛/온도감/식단·칼로리/밀키트/음료/예산/알레르기)을 선택해 AI 추천을 받는다. 마스터 메뉴와 실시간 연동.
