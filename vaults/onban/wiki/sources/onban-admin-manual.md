# 온반 관리자 페이지 사용 매뉴얼

## Overview
menu-manager.html(관리자/운영자 페이지)의 전체 사용법을 다루는 2026-08-10자 매뉴얼. 로그인, 5개 탭(메뉴 관리 / 카카오 발송 / 주문 관리 / 메뉴 창고 / 설정), 이미지 갤러리 관리자 모드까지 관리자가 쓰는 모든 기능을 포괄한다. [[onban-operator-manual-v1]] (2026-04 작성)의 상위 호환 버전으로, 실시간 저장 도입·주문 관리 탭 신설·예약주문 처리·설정 세분화 등이 추가되었다.

## Key Takeaways
> ✅ **2026-08-26 갱신**: 원본 문서의 3.4절이 2026-08-20 이후의 실제 동작(실시간 저장 폐지)을 반영하지 못하고 있던 것을 코드 대조로 발견해, 원본 HTML(`관리자페이지_사용매뉴얼.html`)과 이 raw 사본을 직접 수정했다. 아래 Key Takeaways는 수정 후 현재 상태 기준. 변천사 전체는 [[realtime-autosave]] 참고.

- **일일 메뉴 저장은 명시적 버튼 방식**: 메뉴 추가·수정·삭제·재고·가격 변경은 화면에만 우선 반영되고, "💾 일일 메뉴 저장"을 눌러야 서버·고객 화면에 반영된다. 저장 중엔 전체 화면이 차단되고(홈으로 가기만 예외), 저장 없이 탭을 이동하면 확인창 후 편집 내용이 버려지며, 브라우저 새로고침은 그 확인창조차 없이 조용히 편집 내용을 날린다 → [[realtime-autosave]]
- **카카오 발송이 양방향**: 오늘 메뉴 → 카카오 발송 문구 생성뿐 아니라, 카카오톡에 붙여넣던 텍스트를 반대로 파싱해 일일 메뉴로 등록하는 기능도 있다 (구분: 기존/★신메뉴/중복됨, 적색 라인 = 확인 필요) → [[kakao-dispatch]]
- **예약주문은 별도 상태 체계가 없다**: 일반 주문과 동일한 4단계(대기중→주문접수→배송완료/취소된주문)를 따르며, "예약 날짜가 지정되어 있는가"만으로 구분된다. 재고 차감/부족 검사도 예약주문에는 적용되지 않는다 → [[reservation-order]]
- **알림톡은 배송완료 시점 단 1회**: 접수·확정 단계에서는 고객에게 아무 것도 발송되지 않음 — 카카오 대화방으로 접수 알림이 가면 고객이 그 자리서 답장해 예전 방식으로 회귀하는 문제 때문. 관리자에게는 새 주문/변경/취소 시 SMS가 간다.
- **배송업체 SMS는 실제로 미사용**: 설정의 배송업체 연락처 칸을 비워두면 배송업체 문자가 나가지 않음 (실무에서 이 기능 자체를 쓰지 않음 — 이 vault 밖 프로젝트 메모리와도 일치하는 내용)
- **이미지 갤러리가 이중 모드**: 같은 비밀번호로 로그인된 기기에서 고객용 갤러리(온반_메뉴_이미지갤러리.html)를 열면 관리자 모드로 전환되어, 카드 클릭이 상세보기 대신 마스터 메뉴 편집 팝업으로 바뀐다 → [[onban-image-gallery]]

## Detailed Notes

### 탭 구조
🍱 메뉴 관리 / 💬 카카오 발송 / 📦 주문 관리 / 🗄 메뉴 창고 / ⚙ 설정 — 5개 탭. 메뉴 관리 탭은 진입 시 카테고리 필터가 항상 '전체'로 초기화된다.

### 메뉴 관리
일일 메뉴 추가 폼(카테고리·메뉴명·금액(천원)·재고·어린이 여부)에 더해 🔍 메뉴 검색으로 마스터 메뉴에서 자동 채우기 가능. 재고 -1 입력 시 "조리준비중" 표시. "+신 메뉴"로 마스터에 없는 메뉴 즉시 등록 가능.

### 카카오 발송 (상세는 [[kakao-dispatch]])
발송 텍스트 칸은 항시 편집 가능하며, 직접 수정한 내용은 자동 폴링 갱신이 덮어쓰지 않는다. 금액 형식은 `10`(천원)/`6천원`/`6,000원`/`6.5천원`을 모두 인식.

### 주문 관리
15초 자동 갱신 + 수동 새로고침 버튼. 상태: 대기중 → 주문접수 → 배송완료, 또는 취소된주문. 예약주문은 상태 라벨 앞에 빨간 "예약주문 / " 접두어가 붙어 구분된다 (5.5절, [[reservation-order]]).

### 메뉴 창고
"날짜별 메뉴 묶음"(일일 메뉴 이력)이 기본 표시. 전체 마스터 메뉴 탭에서 선택 항목을 오늘의 메뉴로 보내기/삭제/병합(정확히 2개 선택 시) 가능. "예약된 메뉴" 탭은 작업일자 이후로 접수 완료된 예약주문만 모아 보여준다 → [[menu-warehouse]]

### 설정
기본 재고값, 계좌 정보(복수 등록 가능), 관리자 연락처/이메일/배송업체, 발송 설정(SMS/알림톡 토글, 저장 버튼 없이 즉시 적용), 카테고리 관리, 예약 이벤트 관리(이벤트 메뉴명·설명·가격·예약 기한 — 저장/비우기).
