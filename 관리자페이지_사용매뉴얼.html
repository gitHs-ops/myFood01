1. 접속 및 로그인

관리자 페이지(menu-manager.html)에 접속하면 비밀번호 입력 창이 표시됩니다.

  • 올바른 비밀번호 입력 시 관리자 화면으로 진입합니다.
  • 비밀번호가 틀리면 페이지가 닫힙니다.
⚠ 비밀번호는 외부에 노출되지 않도록 주의하세요.

2. 화면 구성 — 탭 메뉴

상단 탭으로 각 기능 페이지를 전환합니다.

탭기능
🍱 메뉴 관리일일 메뉴 추가·편집·재고 조정 및 저장
💬 카카오 발송카카오채널 안내 문자 생성 및 복사
📦 주문 관리접수된 주문 조회·상태 변경·답변
🗄 메뉴 창고과거 일일 메뉴 및 전체 마스터 메뉴 조회
⚙ 설정재고·계좌·관리자 정보·발송·카테고리 설정

3. 🍱 메뉴 관리

3.1 통계 현황

탭 진입 시 상단에 오늘의 주문 통계(주문 수, 금액 등)가 요약 표시됩니다.

3.2 일일 메뉴 추가 등록

항목설명
카테고리메뉴 분류 선택
메뉴명클릭하면 마스터 메뉴 목록에서 선택. 직접 입력도 가능
금액(천원)판매 단가 입력
재고(수량)판매 가능 수량 입력 (-1 입력 시 조리준비중)
어린이 메뉴어린이도 먹을 수 있는 메뉴 여부 체크
메뉴 설명마스터 메뉴에 저장된 설명 자동 표시 (읽기 전용)
  • + 오늘의 메뉴에 추가 버튼으로 목록에 추가합니다.
  • +신 메뉴 버튼으로 마스터에 없는 신규 메뉴를 바로 등록할 수 있습니다.
💡 같은 메뉴를 이미 추가했을 때 중복 경고가 표시됩니다.

3.3 오늘의 메뉴 목록

  • 추가된 메뉴가 카테고리별로 표시됩니다.
  • 각 메뉴 행에서 재고 수량 조정, 가격 수정, 삭제가 가능합니다.
  • ✏️ 수정 버튼으로 메뉴명·설명·이미지 등 마스터 정보를 편집할 수 있습니다.

3.4 일일 메뉴 저장

하단 플로팅 💾 일일 메뉴 저장 버튼을 클릭하면 오늘의 메뉴가 서버에 저장되어 고객 화면에 표시됩니다.

📌 저장 전에는 고객 화면에 반영되지 않습니다. 메뉴 확정 후 반드시 저장하세요.

4. 💬 카카오 발송

4.1 발송 문자 생성 · 편집

  • 오늘메뉴에서 가져오기 버튼으로 현재 일일 메뉴를 카카오 안내 형식으로 자동 생성합니다.
  • 발송 텍스트 칸은 항상 편집 가능합니다(별도 '내용 수정 / 저장' 버튼 없음). 클릭해서 바로 고칠 수 있습니다.
  • 직접 입력하면 자동 갱신(폴링)이 그 내용을 덮어쓰지 않아 편집 내용이 사라지지 않습니다.
  • 수정 내용을 버리고 최신 메뉴로 다시 채우려면 오늘메뉴에서 가져오기를 누르세요.

4.2 텍스트 복사 및 활용

  • 텍스트 복사하기 버튼으로 클립보드에 복사 후 카카오채널에 붙여넣기합니다.

4.3 카카오 톡 내용으로 일일 메뉴 생성 (2단계)

  • 카카오톡 메뉴 텍스트를 발송 칸에 붙여넣고 [카카오 톡 내용으로 일일 메뉴 생성] 버튼을 누릅니다.
  • 1차 · 미리보기: 파싱 결과가 표로 재표시됩니다 — 메뉴ID | 메뉴명 | 금액 | 구분. 이 표는 직접 수정 가능하니 등록 전에 확인·편집하세요.
  • 2차 · 등록: 같은 버튼을 다시 누르면 표 내용대로 일일 메뉴에 등록됩니다. 등록 기준은 메뉴명이며 중복은 자동 제외됩니다.

구분 표시 — 기존(창고에 있는 메뉴) · ★신메뉴(창고에 없는 새 메뉴) · 중복됨(같은 이름이 반복됨).

📌 적색 라인 = 확인 필요. 다음 항목은 라인 전체가 적색으로 강조됩니다 — 중복됨 · ★신메뉴 · 금액 10만원 이상(⚠금액확인) · 메뉴명 문자 깨짐(⚠문자깨짐) · 금액 없음/0/음수(⚠금액없음). 적색 라인은 표에서 수정하거나 해당 줄을 지운 뒤 등록하세요.

금액 형식은 한우육전 10(천원 단위 숫자) · 6천원 · 6,000원 · 6.5천원 을 모두 인식합니다. 금액은 천원 단위로 저장됩니다(예: 6.5 = 6,500원).

💡 기존에 카카오채널로 관리하던 메뉴를 빠르게 가져올 때 유용합니다.

5. 📦 주문 관리

5.1 주문 목록

  • 접수된 주문이 실시간으로 표시됩니다. 15초마다 자동 갱신됩니다.
  • 실시간 변경 확인! 버튼으로 즉시 새로고침할 수 있습니다.
  • 상태별 필터 탭으로 주문을 분류해서 볼 수 있습니다.

5.2 주문 상태

상태설명
대기중고객이 주문을 완료하고 접수 대기 중인 상태
주문접수관리자가 주문을 확인·접수한 상태
배송완료배송 또는 픽업이 완료된 상태
취소된주문주문이 취소된 상태
📌 예약주문 전용 상태는 따로 없습니다. 예약주문도 위 네 가지 상태를 일반 주문과 똑같이 거치며, "예약 날짜가 지정되어 있는지"만 다릅니다. 자세한 내용은 5.5절 참고.

5.3 주문 상세

주문 행을 클릭하면 상세 팝업이 표시됩니다.

  • 주문자 정보(이름·연락처·주소·배송방법) 확인
  • 주문 메뉴 목록·수량·금액 확인
  • 상태 변경 버튼으로 주문 상태 업데이트
  • 추가 요청사항 확인 및 관리자 답변 입력
💡 배송완료로 변경하면 고객에게 카카오 알림톡이 자동 발송됩니다(설정에서 끌 수 있음). 접수완료·취소는 고객에게 발송되지 않으며, 관리자에게는 새 주문·주문 변경·취소 시 SMS가 갑니다. 자세한 발송 규칙은 7.4절 참고.

5.4 추가 요청 처리

  • 고객이 입력한 추가 요청사항이 주문 상세에 표시됩니다.
  • 답변 입력란에 내용을 작성하면 고객 주문내역 화면에 💬 온반 답변으로 표시됩니다.
  • 미처리 추가 요청이 있으면 탭 뱃지(숫자)가 표시됩니다.

5.5 예약주문 처리

고객이 예약주문 페이지에서 신청한 건은 예약주문 필터 탭에서 모아 볼 수 있습니다. 예약주문 여부는 오직 예약 날짜 지정 여부로만 판별하므로, 이 탭에는 아직 접수 전인 건뿐 아니라 작업일자 기준으로 오늘 신청·접수 처리된 예약주문도 함께 표시됩니다.

구분설명
상태 라벨예약 날짜가 지정된 주문은 상태 라벨 앞에 빨간 예약주문 / 접두어가 붙어 일반 주문과 구분됩니다 (예: 예약주문 / 주문접수)
예약 날짜 표시목록 행과 상세 팝업에 예약 날짜 배지(📅)가 별도로 표시됩니다
✅ 예약 주문 접수대기 중인 예약주문을 접수 처리. 접수 시 주문 날짜가 고객이 지정한 예약 날짜로 자동 변경됩니다. 처리 자체는 일반 주문 접수와 동일한 흐름입니다
✅ 배송완료접수된 예약주문은 작업일자가 예약 날짜와 같을 때만 배송완료 처리가 가능합니다. 날짜가 다르면 버튼이 비활성화됩니다
재고 처리예약주문은 일반 주문과 달리 재고 차감/재고 부족 검사를 적용받지 않습니다
📌 상세 팝업 하단 액션 버튼은 상태와 무관하게 항상 [주요 처리 버튼] [✕ 삭제] [닫기] 한 줄로 통일되어 있습니다.

6. 🗄 메뉴 창고

6.1 일일 메뉴 이력

  • 날짜별로 저장된 과거 일일 메뉴를 조회할 수 있습니다.
  • 과거 메뉴를 참고하여 오늘의 메뉴를 구성할 때 활용합니다.

6.2 전체 마스터 메뉴

  • 등록된 전체 마스터 메뉴 목록을 카테고리별로 조회합니다.
  • 메뉴명·가격·설명·이미지 등 마스터 정보를 확인·편집할 수 있습니다.

6.3 예약된 메뉴

마스터 메뉴 탭 우측의 예약된 메뉴 탭에서, 작업일자 이후로 접수 완료된 예약주문만 모아서 조회할 수 있습니다.

  • 목록 행에는 고객명·연락처·주문 생성 시각·예약 날짜·메뉴 요약·합계 금액이 표시됩니다.
  • 행을 클릭하면 주문 상세 팝업이 열리며, 날짜와 무관하게 항상 조회 가능합니다.
  • 작업일자를 변경하면 목록이 자동으로 새로고침됩니다.
  • 다른 탭으로 이동했다가 다시 예약된 메뉴 탭으로 돌아오면 항상 최신 상태로 강제 갱신됩니다.
  • 상세 팝업에서 ✕ 삭제 처리 시 목록에서 즉시 사라집니다.

7. ⚙ 설정

7.1 기본 재고 설정

  • 메뉴 추가 시 자동 적용되는 초기 재고량을 설정합니다.
  • 저장 버튼 클릭 후 적용됩니다.

7.2 계좌 정보 관리

  • 고객 결제 안내에 표시되는 계좌를 등록·관리합니다.
  • 은행명·예금주·계좌번호를 입력 후 추가합니다.
  • 여러 계좌 등록이 가능합니다.

7.3 관리자 정보

항목설명
연락처관리자 휴대폰 번호 — 새 주문·주문 변경·주문 취소 SMS 수신 대상
이메일관리자 이메일
배송업체배송업체 연락처. 실제 업무에서는 사용하지 않으며, 이 칸을 비워두면 배송업체 문자는 발송되지 않습니다

7.4 발송 설정

항목설명
💬 문자(SMS) 발송주문 확정·주문변경·주문취소 시 관리자에게 SMS 자동 발송
🔔 알림톡 발송고객에게 배송완료 시점에만 카카오 알림톡을 보냅니다. 주문 접수 시점에는 보내지 않습니다 — 접수 알림톡이 카카오 대화방으로 가면 고객이 그 자리에서 답장해 예전 카톡 주문 방식으로 되돌아가기 때문입니다
📌 발송 기능은 토글 스위치로 ON/OFF 가능합니다. 토글을 움직이면 그 자리에서 바로 저장됩니다(별도 저장 버튼 불필요).
📌 고객에게 나가는 알림톡은 배송완료 시점 하나뿐입니다. 고객이 주문을 수정하거나 취소해도 고객 본인에게는 아무것도 발송되지 않으며 — 그 내용은 관리자에게만 SMS로 전달됩니다(위 SMS 발송 항목). 접수·확정 단계에서도 고객에게는 발송되지 않습니다.

7.5 카테고리 관리

  • 메뉴 분류에 사용되는 카테고리를 추가·수정·삭제할 수 있습니다.

7.6 예약 이벤트 관리

고객의 오늘의 메뉴/예약주문 페이지 상단에 노출되는 특별 예약 카드를 등록합니다.

항목설명
이벤트 메뉴명이벤트로 안내할 메뉴 이름
메뉴 설명고객 화면 요약 카드에 표시되는 소개 문구
메뉴 가격천원 단위 판매 가격
예약 기한이 날짜까지만 카드가 노출됨. 고객이 예약 날짜를 선택할 때도 기한일부터 1주일 이내로 범위가 제한됨
  • 저장 버튼으로 등록·수정, 비우기 버튼으로 이벤트를 완전히 내릴 수 있습니다(이벤트 메뉴명이 비어 있으면 고객 화면에 노출되지 않음).
  • 고객이 이벤트 카드를 클릭하면 일반 예약주문과 동일한 팝업이 열리며, 같은 전화번호로 같은 날짜에 중복 신청하면 서버에서 자동으로 거부됩니다.

8. 이미지 갤러리 관리자 모드

고객용 이미지 갤러리 화면(온반_메뉴_이미지갤러리.html)도 이 관리자 페이지와 같은 비밀번호로 로그인된 기기에서 열면 관리자 모드로 동작합니다. 별도 로그인 절차는 없으며, 이 페이지(menu-manager.html)에 로그인되어 있던 기기의 브라우저로 갤러리 링크를 열면 자동으로 인식됩니다.

  • 일반 고객에게는 사진 카드를 클릭하면 상세 보기 팝업만 열리지만, 관리자 모드에서는 같은 클릭이 메뉴 편집 팝업으로 바뀝니다(메뉴명·카테고리·가격·재고·설명·이미지 — 메뉴 관리 탭의 편집 팝업과 동일한 항목).
  • 저장하면 마스터 메뉴 한 건만 즉시 갱신됩니다. 오늘의 메뉴 목록 전체를 다시 저장하는 것이 아니므로, 다른 날짜·다른 메뉴에는 영향을 주지 않습니다.
  • 일반 고객 화면(비로그인 기기)에서는 이 편집 기능이 전혀 노출되지 않고, 지금까지와 동일하게 조회만 가능합니다.
💡 매장 밖에서 사진을 훑어보다가 오탈자나 가격 오류를 발견했을 때, menu-manager.html로 돌아가지 않고 그 자리에서 바로 고칠 수 있습니다.
