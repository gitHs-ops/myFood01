1. 화면 구성 개요

온반 고객 페이지는 단일 HTML 앱으로, 아래의 화면(페이지)이 전환되며 동작합니다.

화면역할
메뉴 목록오늘 판매 중인 메뉴를 카테고리별로 조회
메뉴 상세 팝업메뉴명 클릭 시 사진·가격·설명 미리보기 + 장바구니 담기
메뉴 상세 페이지수량 선택 후 장바구니 또는 바로 주문

주문자 정보 입력이름·연락처·주소·요청사항 입력
주문 확정하기최종 주문 내용 확인 후 주문 확정
결제 안내계좌 이체 정보 및 금액 안내
주문 내역오늘 주문 조회·수정·취소·추가 요청
💡 페이지 새로고침 없이 상단 버튼으로 화면 전환이 가능합니다.

3. 메뉴 목록 페이지

3.1 날짜 배너

화면 상단에 오늘 날짜와 자동 갱신 카운트다운이 표시됩니다.

  • 카운트다운이 0이 되면 메뉴 목록이 자동으로 갱신됩니다.
  • 오늘 등록된 메뉴가 없으면 "오늘 등록된 메뉴가 없어요." 메시지가 표시됩니다.

3.2 예약 이벤트 카드

운영자가 예약 이벤트를 등록해 두면, 날짜 배너 바로 아래에 🎉 예약 이벤트 배지 · 설명 · 예약 기한이 한 줄로 요약된 카드가 표시됩니다.

  • 카드를 클릭하면 페이지 이동 없이 바로 예약 신청 팝업이 열립니다.
  • 이벤트가 등록되어 있지 않거나 예약 기한이 지나면 카드는 표시되지 않습니다.
  • 동일한 카드가 예약주문 페이지 상단에도 나타나며, 자세한 신청 방법은 11.6절을 참고하세요.

3.4 메뉴 카드

각 메뉴는 카드 형태로 표시되며, 구성 요소는 다음과 같습니다.

요소설명
카테고리 색 점 (●)카테고리를 색상으로 표시
썸네일 이미지 / 이모지메뉴 사진 또는 음식 이모지
메뉴명메뉴 이름 (한우/한돈/밀키트는 괄호 표시)
어린이 태그어린이 식단 포함 메뉴에 노란 태그 표시
재고 태그잔여 수량이 3개 이하면 ⚠ 3개 남음 형태로 표시
품절 태그재고 소진 시 품절 표시, 선택 불가
가격단위: 천원 (예: 6천원 = 6,000원)
체크박스 ☑클릭하면 장바구니에 바로 추가
📌 노란 왼쪽 테두리가 있는 메뉴는 어린이 식단에 포함되는 메뉴입니다.

3.5 메뉴 선택 방법

방법 1 — 체크박스 클릭 (빠른 담기)

  1. 메뉴 카드 우측 체크박스를 클릭합니다.
  2. 체크박스가 초록으로 변하며 장바구니에 수량 1개가 담깁니다.
  3. 화면 하단에 🛒 장바구니 보기 플로팅 버튼이 나타납니다.

방법 2 — 메뉴명 클릭 (상세 팝업)

  1. 메뉴명을 클릭하면 상세 팝업이 나타납니다.
  2. 사진, 가격, 설명을 확인 후 장바구니 담기 또는 닫기 버튼을 선택합니다.

7. 주문자 정보 입력

7.1 입력 항목

항목필수 여부설명
이름필수 *주문자 성명 (최대 20자)
전화번호필수 *주소 목록 조회 및 주문 연동에 사용
배송주소픽업 외 필수직접 입력 또는 📋 목록에서 선택
배송방법-경비원실 / 문앞 / 택배함 / 현관에서 직접 수령 / 매장 픽업 (기본값: 경비원실)
추가요청선택자유 형식 입력 (최대 200자)

7.2 자동 채우기

기기를 재방문하면 이전에 저장된 이름 · 전화번호 · 주소1이 자동으로 채워집니다. 별도 로그인 없이 기기 식별 방식으로 동작합니다.

7.3 주소 목록 기능

  • 이름과 전화번호를 입력하면 📋 목록 버튼이 활성화됩니다.
  • 버튼 클릭 시 저장된 주소(최대 3개: 주소1 · 주소2 · 주소3)가 팝업으로 표시됩니다.
  • 각 주소 우측 선택 버튼을 누르면 배송주소에 즉시 반영됩니다.
  • ✏️ 수정 버튼으로 저장된 주소를 편집할 수 있습니다.

7.4 배송방법

매장 픽업 선택 시 배송주소 입력이 불필요합니다. 배송방법은 항목 선택만으로 지정되며 별도 확인 메시지는 표시되지 않습니다.

7.5 주문 내용 확인 박스

주문자 정보 입력 화면 하단에 선택한 메뉴 · 수량 · 금액 요약이 표시됩니다.

8. 주문 확정하기

주문자 정보 입력 다음으로 최종 확인 화면입니다.

  • 주문 메뉴 목록 및 수량, 금액이 표시됩니다.
  • 총 합계 금액이 초록 박스에 강조 표시됩니다.
  • 📦 주문 확정하기 버튼(노란색)을 클릭하면 주문이 접수되고 결제 안내 화면으로 이동합니다.
📌 주문 확정 후에는 주문 번호가 생성되며 주문 내역에서 확인할 수 있습니다.

9. 결제 안내 페이지

주문 요청 후 계좌 이체 방식으로 결제합니다.

9.1 계좌 정보

항목내용

9.2 결제 진행 방법

  1. 계좌번호 복사 버튼을 클릭하여 계좌번호를 클립보드에 복사합니다.
  2. 본인 은행 앱에서 이체를 진행합니다.
  3. 이체 완료 후 입금자명을 주문자 이름으로 기재합니다.
📌 결제 금액은 주문 화면의 총 합계 금액과 동일하게 이체하세요.
⚠ 이체 후 입금 확인까지 최대 수 분이 소요될 수 있습니다. 확인 완료 시 주문 상태가 변경됩니다.

10.4 추가 요청 (주문 후 메모)

  1. 주문 상세 팝업 하단 "+ 추가 요청 입력" 버튼을 클릭합니다.
  2. 텍스트 박스에 내용을 입력합니다.
  3. 저장 버튼을 클릭하면 관리자에게 전달됩니다.
  4. 저장 후 수정도 가능합니다 (✏ 수정 버튼).

11. 예약주문

오늘 판매 중인 메뉴 외에, 향후 배송 받고 싶은 날짜를 지정해 미리 주문할 수 있는 기능입니다. 상단 📅 예약주문 버튼으로 이동합니다.

11.1 메뉴 선택

요소설명
카테고리 탭마스터(창고) 메뉴 전체를 카테고리별로 조회
메뉴 카드클릭하면 선택(체크) 상태로 전환, 다시 클릭하면 해제
이전 / 다음메뉴가 많을 경우 페이지 단위로 이동

11.2 하단 플로팅 바

메뉴를 1개 이상 선택하면 화면 하단에 선택 개수 뱃지 + 📅 예약 주문 신청하기 버튼이 항상 화면에 떠 있는 형태(플로팅)로 표시됩니다. 스크롤을 내려도 계속 화면에 남아 있습니다.

📌 선택한 메뉴가 없으면 버튼이 회색으로 비활성화됩니다.

11.3 예약 주문 신청 팝업

예약 주문 신청하기 버튼을 누르면 "예약주문" 타이틀의 팝업이 열리며, 선택한 메뉴 목록과 함께 아래 항목을 입력합니다. 항목 구성과 배치는 일반 주문자 정보 입력 화면과 동일합니다. 팝업 하단에는 저장 / 닫기 두 버튼이 있습니다.

항목필수 여부설명
이름필수 *주문자 성명
전화번호필수 *주소 목록 조회에 사용
배송 주소픽업 외 필수직접 입력 또는 📋 목록에서 선택 (일반 주문과 동일한 주소록 공유)
배송 방법필수 *경비원실 / 문앞 / 택배함 / 현관에서 직접 수령 / 매장 픽업
예약 날짜필수 *오늘로부터 1일 후 ~ 7일 이내의 날짜만 선택 가능
요청사항선택자유 입력 (예약 접수 정보와 함께 저장됨)

11.4 배송비 안내

  • 선택한 메뉴 합계가 2만원 미만이면 매장 픽업만 가능합니다.
  • 합계가 2만원 이상이고 배송(픽업 외)을 선택하면 배송비 1천원이 자동으로 합계에 더해집니다.
  • 매장 픽업을 선택하면 배송비가 붙지 않습니다.

11.5 접수 및 진행 상태

예약주문은 일반 주문과 동일한 처리 흐름(대기중 → 주문접수 → 배송완료)을 따릅니다. 별도의 "예약주문" 처리 상태가 있는 것이 아니라, 지정한 예약 날짜 정보를 가진 채로 일반 주문과 똑같이 진행됩니다.

  1. 신청 직후에는 일반 주문과 같은 대기중 상태로 등록됩니다.
  2. 관리자가 신청 내용을 확인 후 접수 처리하면, 지정한 예약 날짜에 맞춰 배송이 준비됩니다.
  3. 예약 날짜 당일 배송/픽업이 완료되면 배송완료로 상태가 바뀝니다.

진행 상태는 주문내역 화면에서 일반 주문과 함께 확인할 수 있으며, 예약 날짜가 지정된 주문은 타임스탬프 옆에 빨간색 예약주문 (MM/DD) 표시가 함께 나타납니다. 관리자가 접수 처리를 완료해 주문 날짜가 예약일자로 바뀐 뒤에도 주문내역에서 계속 확인할 수 있습니다.

⚠ 예약 날짜는 신청 후 별도로 변경할 수 없습니다. 날짜를 잘못 선택한 경우 취소 후 다시 신청해 주세요.

11.6 예약 이벤트

운영자가 특정 기간 동안 특별히 안내하는 메뉴를 예약 이벤트로 등록할 수 있습니다. 등록되어 있으면 오늘의 메뉴 페이지와 예약주문 페이지 상단에 배지·설명·기한이 한 줄로 요약된 카드가 표시됩니다.

  • 카드를 클릭하면 페이지 이동 없이 바로 예약 신청 팝업이 열립니다.
  • 예약 이벤트를 신청할 때는 예약 날짜를 이벤트 기한일부터 1주일 이내에서만 선택할 수 있습니다 (일반 예약주문의 "오늘로부터 1~7일" 규칙과 다름).
  • 같은 전화번호로 같은 날짜에 동일한 예약 이벤트를 중복 신청할 수 없습니다. 이미 신청한 날짜를 다시 선택하면 안내 메시지가 표시됩니다.
  • 이벤트 기한이 지나면 카드가 자동으로 사라집니다.

12. AI추천메뉴 (이미지 갤러리)

메뉴를 사진으로 훑어보며 고를 수 있는 이미지 갤러리 화면입니다. 상단 🎯 AI 추천메뉴 버튼으로 진입하면 전체 메뉴가 사진 카드로 표시되고, AI에게 취향을 알려주면 어울리는 메뉴를 골라줍니다.

12.1 갤러리 화면

요소설명
카테고리 탭 / 검색메뉴 목록과 동일하게 카테고리별 필터, 전체검색·카테고리내검색 지원
사진 카드메뉴 사진이 없으면 접시 이모지 플레이스홀더로 표시
카드 클릭메뉴 사진·가격·설명을 보여주는 상세 팝업이 열림
오늘의 메뉴 보기오늘 판매 중인 메뉴만 필터링해서 볼 수 있음
예약 주문 신청하기보고 있는 메뉴로 바로 예약주문 화면으로 이동
💡 갤러리는 마스터 메뉴와 실시간으로 연동되어, 관리자가 메뉴를 추가·수정하면 새로고침 시 바로 반영됩니다.

12.2 AI 추천 요청하기

🎯 AI추천메뉴 버튼을 누르면 추천 조건을 입력하는 팝업이 열립니다.

  1. 화면 상단에서 추천 범위를 고릅니다: 오늘의 메뉴에서 추천받기 / 전체 메뉴중에서 추천 받기 / 개인취향으로 추천받기 중 하나를 선택합니다.
  2. 식사 목적·형태·음식 종류·국물 유무·맛/매운정도·온도감·식단/칼로리·밀키트 여부·곁들일 음료·예산 범위·알레르기(비선호 재료) 등 원하는 항목만 선택합니다. 모두 비워두면 "특별한 조건 없이 골고루" 추천합니다.
  3. 실행 버튼을 누르면 AI가 조건에 맞는 메뉴 3~6개를 고릅니다.
📌 개인취향으로 추천받기는 내가 그동안 살펴본 메뉴, 예전에 AI추천에서 실제로 골랐던 메뉴 이력을 참고해서 추천합니다. 아직 이용 이력이 없으면 인기 메뉴 위주로 추천됩니다.

12.3 추천 결과 확인 및 적용

추천이 완료되면 입력 화면 하단에 추천 이유와 함께 메뉴 적용 / 취소 버튼이 나타납니다. 조건에 맞는 메뉴가 하나도 없으면, 어떤 조건이 서로 부딪혔는지 화면 중앙 안내 메시지로 설명해 주므로 조건을 조정해 다시 시도할 수 있습니다.

버튼동작
메뉴 적용추천받은 메뉴만 갤러리에 표시되고, 각 카드에 선택 체크박스가 나타남(기본 전체 선택)
취소추천을 적용하지 않고 전체 메뉴 화면으로 돌아감

12.4 추천 메뉴로 예약주문 신청

  1. 추천 적용 후, 원하지 않는 메뉴는 카드(또는 체크박스)를 눌러 선택 해제합니다.
  2. 하단 예약 주문 신청하기 버튼을 누르면, 체크된 메뉴들이 한 번에 예약주문 화면으로 전달되어 바로 신청 팝업이 열립니다.
💡 이전에는 메뉴 1개만 예약으로 넘길 수 있었지만, 지금은 추천받은 메뉴 여러 개를 한 번에 예약 신청할 수 있습니다.

14. 자주 묻는 질문 (FAQ)

Q. 장바구니에 담았는데 새로 고침하면 사라지나요?

네. 장바구니 내용은 임시 저장이므로 페이지를 닫거나 새로 고침하면 초기화됩니다. 주문은 담은 즉시 진행하시기를 권장합니다.

Q. 품절 메뉴는 어떻게 알 수 있나요?

메뉴 카드에 품절 태그가 표시되며, 카드 전체가 흐릿하게 표시됩니다.

Q. "임시 이미지" 배지는 무엇인가요?

메뉴 대표 사진이 아직 확정되지 않은 임시 이미지입니다. 실제 음식 사진으로 업데이트 예정입니다.

Q. 매장 픽업은 어떻게 신청하나요?

주문자 정보 입력 화면의 요청사항에서 "매장 픽업"을 선택하시면 됩니다. 배송 주소 입력은 불필요합니다.

Q. 주문 취소는 어디서 하나요?

주문내역 → 해당 주문 클릭 → 하단 주문 취소 버튼. 단, 접수중 상태일 때만 가능합니다.

Q. 계좌번호를 잘못 이체했어요.

주문 상세 팝업의 추가 요청 기능을 통해 관리자에게 메모를 남겨 주세요.
